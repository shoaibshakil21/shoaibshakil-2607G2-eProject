BEAUTY OF BEACHES - APTECH HTML5 EPROJECT
========================================

HOW TO RUN
1. Extract the ZIP file.
2. Open the extracted Beauty-Of-Beaches folder in Visual Studio Code.
3. Open index.html using Live Server, or open it directly in a modern browser.
4. Internet access is needed for Bootstrap-free remote images and Google Fonts.

PROJECT STRUCTURE
- index.html       Home page
- about.html       About Us page
- gallery.html     Gallery page
- north.html       North Zone page
- south.html       South Zone page
- east.html        East Zone page
- west.html        West Zone page
- feedback.html    Feedback page
- queries.html     Queries page
- contact.html     Contact page
- sitemap.html     Sitemap page
- css/style.css    Shared responsive styling
- js/common.js     Shared navbar, footer, ticker, visitor demo and form demo

IMPORTANT NOTES
- The navbar and footer are shared and inserted by js/common.js.
- The visitor count uses localStorage and is only a browser-local demonstration, not a global analytics counter.
- Feedback and Queries forms are front-end demonstrations only. They do not send or store data on a server.
- Geolocation requires user permission and generally works on HTTPS or localhost.
- Contact details are placeholders. Replace them with the real organization details before final submission.
- Zone cards contain illustrative image/content examples. Research and add accurate beach names, countries, descriptions and travel information.
- Images are loaded from Unsplash URLs, so an internet connection is required.
